## Integración con el contexto Proyecto

`CONTEXT.md` es el contexto operativo persistente del proyecto. Antes de realizar trabajo relevante, el agente debe leerlo y utilizarlo como referencia del estado actual. Debe actualizarlo cuando cambien decisiones, estado operativo, arquitectura, bloqueos, riesgos o el punto exacto de continuación. La información registrada debe distinguir hechos verificados, decisiones y elementos no verificados. Nunca deben almacenarse contraseñas, tokens, claves API ni otros secretos en `CONTEXT.md`.
